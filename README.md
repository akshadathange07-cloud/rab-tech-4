# RabTech Academy — Task 04
## Responsive Design Tokens & Mobile-First CSS Architecture

This is a ready-made responsive dashboard.

### Included
- CSS custom properties/design tokens in `:root`
- Responsive CSS Grid
- 320px, 768px, 1024px and 1440px breakpoints
- Glassmorphism/backdrop blur
- Soft shadows and hover transitions
- Light/dark theme variables and theme toggle
- Mobile-first layout
- No intentional horizontal scrolling

### Important GitHub Pages upload structure
Keep the folders exactly like this:

```text
RabTech-4/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

Do NOT put `style.css` and `script.js` in a different folder.

### Proof
Resize the browser and capture real screenshots at approximately 320px, 768px, 1024px and 1440px. Add those screenshots to the repository before submitting.
